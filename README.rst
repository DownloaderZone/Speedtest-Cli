speedtest-cli
=============

Command line interface for testing internet bandwidth using speedtest.net.

Repository: https://github.com/DownloaderZone/Speedtest-Cli

Official Ookla Speedtest CLI
----------------------------

**Always use official**: For maximum throughput (especially gigabit/multi-gigabit lines), official Ookla latency measurement, and server compatibility, the official Ookla Speedtest CLI binary is recommended.

To remove legacy speedtest-cli and install the official Ookla Speedtest CLI:

::

    sudo apt-get remove speedtest-cli
    sudo apt-get install curl
    curl -s https://packagecloud.io/install/repositories/ookla/speedtest-cli/script.deb.sh | sudo bash
    sudo apt-get install speedtest

This Python CLI automatically detects and delegates to the official Ookla binary when installed on your system. You can force official delegation with ``--official`` or force the pure Python implementation with ``--pure-python``.

Supported Python Versions
-------------------------

``speedtest-cli`` requires **Python 3.8+** (tested through Python 3.8, 3.9, 3.10, 3.11, 3.12, 3.13, and 3.14+).

Legacy Python 2.x and ancient Python 3 (< 3.8) support has been completely removed to ensure high reliability, modern TLS security, and standard library compliance.

Installation
------------

Pip / PyPI
~~~~~~~~~~

::

    pip install dz-speedtest-cli

or directly from GitHub:

::

    pip install git+https://github.com/DownloaderZone/Speedtest-Cli.git

Github
~~~~~~

::

    git clone https://github.com/DownloaderZone/Speedtest-Cli.git
    cd Speedtest-Cli
    python setup.py install

Direct Download
~~~~~~~~~~~~~~~

::

    curl -Lo speedtest-cli https://raw.githubusercontent.com/DownloaderZone/Speedtest-Cli/master/speedtest.py
    chmod +x speedtest-cli

Inconsistency
-------------

It is not a goal of this application to be a reliable latency reporting tool.

Latency reported by this tool should not be relied on as a value indicative of ICMP
style latency. It is a relative value used for determining the lowest latency server
for performing the actual speed test against.

There is the potential for pure Python HTTP-based tests to report results lower than official socket-based tests on high bandwidth connections (gigabit+). For official line rates, install the official Ookla CLI via the instructions above.
